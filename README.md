## ⚙️ Run Locally

### Prerequisites

- [Bun](https://bun.sh/) (or [Node.js](https://nodejs.org/) v18+ with npm)

### Steps

1. Clone the repository

   ```bash
   git clone https://github.com/rowshanara01/full-stack-web-developer---ai-engineer-portfolio.git
   cd full-stack-web-developer---ai-engineer-portfolio
   ```

2. Install dependencies

   ```bash
   bun install
   ```

   Using npm instead: `npm install`

3. Create your environment file

   ```bash
   cp .env.example .env
   ```

   On Windows Command Prompt, use `copy .env.example .env`, then add your own values.

4. Start the development server

   ```bash
   bun run dev
   ```

   Using npm instead: `npm run dev`

5. Open the address shown in the terminal (usually `http://localhost:5173`)

### Build for production

```bash
bun run build
```

## 🔐 Environment Variables

Copy `.env.example` to `.env` and set your own values. Never commit your `.env` file to GitHub.
